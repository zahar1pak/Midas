## 2. Полная синхронизация Telegram-бота с Веб-приложением
- [x] **Единое хранилище и эндпоинты в API**:
  - В `api/app/routers/transactions.py` реализовать полноценный CRUD:
    - `GET /transactions?telegram_id={id}` — список всех операций пользователя
    - `POST /transactions` — создание операции (от бота или из WebApp)
    - `PUT /transactions/{id}` — редактирование
    - `DELETE /transactions/{id}` — удаление
    - `DELETE /transactions/all?telegram_id={id}` — сброс всех данных под PIN-кодом
- [x] **Синхронизация Telegram ID**:
  - При открытии WebApp из Telegram автоматически передавать `telegram_id` пользователя.
  - Все операции, добавленные голосом или текстом в боте, сохраняются под этим `telegram_id` и мгновенно появляются в веб-приложении при обновлении/открытии.
  - Команда бота `/stats` запрашивает актуальные суммы (доходы, расходы, копилка) прямо из базы данных.

## 4. Высокоточное распознавание речи (Whisper AI) и финансовый парсинг
- [x] **Обновление движка распознавания (`voice_service.py`)**:
  - Интеграция быстрого облачного Whisper (Groq `whisper-large-v3-turbo` / OpenRouter Whisper API): распознавание за <0.5 сек с идеальной точностью русского языка, цифр и финансового контекста.
  - Локальный fallback (если нет API-ключа) с предварительной нормализацией аудиофайла `.oga`/`.ogg`.
- [x] **Умный финансовый парсер (`ai_service.py`)**:
  - Поддержка русского сленга: "косарь" / "кусок" = 1000, "пятихатка" = 500, "сотка" = 100, "лям" = 1 000 000.
  - Точное определение типов операций:
    - `expense` (потратил, купил, заправился, оплатил, шаурма, такси)
    - `income` (заработал, получил, зарплата, перевели, аванс)
    - `saving` (отложил, закинул в копилку, спрятал, накопил)
  - Парсинг дат задним числом ("вчера", "позавчера", "на прошлой неделе").
- [x] **Сохранение и обратная связь в боте (`bot/handlers/voice.py`)**:
  - Бот распознает речь, выводит красивое сообщение с типом, суммой и категорией, сохраняет в базу данных и отправляет в статистику веб-приложения.

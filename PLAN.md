# План реализации: Распознавание голосовых и бесшовная синхронизация Телефон <-> ПК

## 1. Контекст и архитектура

Схема взаимодействия компонентов:
```
[Телефон: Telegram @GoldMidaas_bot]
       │ (Голосовое сообщение / Текст)
       ▼
 [Bot Handler (voice.py)] ──(user.id + audio)──► [FastAPI /transactions/voice]
                                                          │
                                     (faster-whisper + Groq AI fallback)
                                                          ▼
                                                  [SQLite DB: midas.db]
                                               (Transaction с telegram_id)
                                                          ▲
                                                          │ (GET /transactions/sync)
                                                          │ (Периодический опрос + фокус)
                                                          ▼
                                         [ПК: Web-приложение в браузере]
                                         (Chrome/Edge или Telegram Desktop)
```

## 2. Выявленные проблемы и точки отказа

1. **Непривязанная категория в API**:
   - В `api/app/routers/transactions.py` в эндпоинтах `/transactions/voice` и `/transactions/text` создавался объект `Transaction`, но поле `category_id` оставалось `None`.
   - При запросе `GET /transactions/sync` транзакции из голосовых сообщений всегда отображались с категорией «Прочее» вместо определенной («Еда», «Транспорт» и т.д.).
2. **Отсутствие связи аккаунтов Телефон <-> Браузер ПК**:
   - В Telegram на телефоне у пользователя реальный `telegram_id` (например, `123456789`).
   - В обычном браузере на ПК `window.Telegram.WebApp` отсутствует, поэтому приложение использовало временный fallback ID. В результате транзакции с телефона не попадали на экран ПК.
3. **Отсутствие непрерывного автообновления**:
   - Запрос на синхронизацию вызывался только один раз при загрузке страницы. Новые голосовые сообщения, отправленные с телефона, появлялись на ПК только после жесткой перезагрузки страницы (F5).
4. **Удобство определения ID**:
   - Пользователю негде было быстро узнать свой цифровой Telegram ID для ввода в браузере на ПК.
